## 📝 Documentation Conventions

### Naming
- **UPPER_CASE.md** - High-level project documents
- **kebab-case.md** - Phase-specific documents
- **CamelCase.md** - Tool-specific documents
- **UPPER_CASE_SUMMARY.md** - Summary documents

### Structure
- **DEMO.html** - Interactive, visual demonstration
- **QUICK_REFERENCE.md** - Bullet points, quick access
- **SETUP_GUIDE.md** - Step-by-step instructions
- **IMPLEMENTATION_SUMMARY.md** - Technical details
- **PLAN.md** - Implementation roadmap
- **SUMMARY.md** - High-level overview

### Links
- Use relative paths: `[text](path/to/file.md)`
- Include file extensions: `.md` or `.html`
- Link to related documents at the bottom

## 🔄 Documentation Updates

### When to Update

**Update QUICK_REFERENCE.md when:**
- Adding new major features
- Changing core workflows
- Adding new packages

**Update SETUP_GUIDE.md when:**
- Adding new setup steps
- Changing development workflow
- Adding new tools

**Update IMPLEMENTATION_SUMMARY.md when:**
- Adding new components
- Changing architecture
- Adding new data structures

**Update PLAN.md when:**
- Adding new features
- Changing implementation approach
- Updating timeline

### How to Update

1. **Check existing documentation** for consistency
2. **Update all related files** (e.g., QUICK_REFERENCE and SETUP_GUIDE)
3. **Keep examples up-to-date**
4. **Maintain table of contents** for long documents
5. **Link to related documents**

## 🎯 Documentation Workflow

### For New Features
1. **Update QUICK_REFERENCE.md** - Add to quick start
2. **Update SETUP_GUIDE.md** - Add to workflow
3. **Update IMPLEMENTATION_SUMMARY.md** - Add technical details
4. **Create examples** - Add to DEMO.html or code samples

### For New Phases
1. **Create phase directory** - `docs/phase-X/`
2. **Create PLAN.md** - Detailed implementation plan
3. **Create SUMMARY.md** - High-level overview
4. **Update QUICK_REFERENCE.md** - Add phase status
5. **Update PROJECT_COMPLETE.md** - Add phase summary

### For Bug Fixes
1. **Update affected documentation**
2. **Fix examples and code samples**
3. **Verify links**
4. **Test workflows**
